Let's do `ls` again. You'll see a file named `data.txt`.

If you `cat` it, you'll see lots of lines. We could read them manually, but that would take a while.

Instead, let's use `grep` to search for the line we need:

`grep "millionth" data.txt`

Congrats!

What we learned in this level:

* How to search inside a file using `grep`.
* How to find specific words or text without reading the entire file manually.
