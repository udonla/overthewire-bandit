Log in to `bandit26` using the previous steps.

List the files:

`ls`

You'll see `bandit27-do`.

Run it to read the next password:

`./bandit27-do cat /etc/bandit_pass/bandit27`

This prints the password for the next level.

**What we learned in this level:**

* Use `ls` to see the files in the current directory.
* Some helper programs let you run commands with different permissions.
* Use `./` to run a program from the current directory.
