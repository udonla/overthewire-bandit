Let's type `ls` to see what's in there. You'll see a directory named `inhere`, so let's go into it with the `cd` command.

Now type `ls` again. Nothing in there? No problem! Type `ls -la` to show all files, including hidden ones. You'll see a file named `...Hiding-From-You`.

Now let's read it with:

`cat ...Hiding-From-You`

What we learned in this level:

* How to enter directories using `cd`.
* How to view hidden files with `ls -la`.
* How to read hidden files using `cat`.
